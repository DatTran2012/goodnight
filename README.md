# Good Night, My Moonlight 🌙

Website chúc ngủ ngon phong cách dreamy anime, viết bằng HTML, CSS và JavaScript thuần.

## Chạy website
1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome, Edge hoặc Safari.
3. Nhấn **Bật nhạc lofi** để bật nhạc nền. Trình duyệt yêu cầu thao tác nhấn của người dùng trước khi phát âm thanh.

## Tùy chỉnh lời chúc
Mở `script.js`, tìm biến `message` và sửa nội dung trong dấu backtick.

## Đổi người nhận
Trong `index.html`, tìm dòng `người đặc biệt` và thay bằng tên hoặc cách xưng hô em muốn.

## Nhạc nền
Nhạc lofi được tổng hợp trực tiếp bằng Web Audio API trong `script.js`, không cần tải file MP3 hoặc kết nối dịch vụ âm thanh bên ngoài. Đây là âm thanh tổng hợp đơn giản, không phải bản thu âm hay bài nhạc thương mại.

## Đưa lên mạng
Có thể tải cả thư mục lên GitHub Pages, Netlify hoặc dịch vụ static hosting bất kỳ. Không cần backend hay cài thư viện.
